# Verification reference

See [Testing](docs/TESTING.md) for reproducible source checks and deployment
acceptance areas. CI results are attached to the exact source commit in
[GitHub Actions](https://github.com/tatselkrik/workforce-suite/actions).

Source tests, a signed package, installation, device behavior and agency file
acceptance are separate checks. A passing source build does not establish the
others. Deployment operators retain their package and acceptance evidence locally.
