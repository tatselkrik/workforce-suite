# Workforce Payroll

Read the root AGENTS.md, local operator instructions if present, and
docs/PAYROLL-DESKTOP.md. Preserve `io.github.tatselkrik.payrolldesktop`, its
independent version, Windows install marker, paths, shortcuts and registration.
Share reviewed financial calculations, adapters and screens through the root library.

Admit only current protected Payroll Officer or Administrator responsibility.
Preserve independent financial approvals, immutable sources, payslips and receipts.
Use the packaged company profile and memory-only authentication. Never package
server keys or persist sessions. Ordinary Employees use Workforce Employee.
Company, personnel and account administration belongs in Workforce HR.

Keep Payroll's package, signing and update identity isolated from HR. Never consume
an HR update in Payroll or infer a new publishing destination from another product's
authorization. Financial rule changes need current official references; deployment,
filing, transfers and external connections require separate applicable authority.
