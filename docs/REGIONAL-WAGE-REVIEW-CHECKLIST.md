# Regional wage review checklist — 0.1.39

- Open Payroll → Wage compliance → Employee checks. Pick dates and search a person.
  Confirm below-floor, missing classification and unsupported dates are distinct.
- Open Classifications. Create a dated review with the actual establishment area,
  industry, headcount evidence and coverage rationale; save it.
- Sign in as a different Administrator to approve. A creator or most recent
  preparer cannot approve their own classification.
- Inspect Rate catalog and its official links. CALABARZON changes on26October;
  Negros Occidental usesVI and Negros Oriental/Siquijor useVIIB.
- Reopen an approved review. It is read-only; retirement retains its history.
  Changed work location/employment type needs a new evidence review.
- Submit a reviewed monthly/cutoff run. Inspect Payroll check history; advisory
  flags are retained even while enforcement is off.
- Administrator: review Enforcement. Enable only after classifications are ready.
  Unresolved checks then block submission/approval; a changed classification after
  submission requires return/resubmission. Issued slips remain unchanged.
- Check light/dark themes and enlarged text. Managers must not see this HR-only tab.

The catalog was verified24October2026, supports dated2026 intervals only and
requires refresh for newer rules. Historical coverage varies by region. The
reference gap is not arrears, and meeting this basic-rate check does not certify
all wage obligations. No salary or tax-status changes happen automatically.
