# Workspaces and optional sections

Workforce HR groups work by responsibility. Overview provides the starting view;
employee records, Hiring, time and leave, services, Development and Reports are
available according to current protected roles. Account Manager is available only
to Administrators. Profile and personal notices remain accessible within the
person's permissions.

Workforce Payroll is the separate application for financial administration.
Workforce HR retains the person's own published pay information and an action to
open a verified local Payroll installation. A Payroll Officer uses Workforce
Payroll; other staff duties alone do not grant financial access.

## Company controls

Administrators configure optional desktop sections in **Settings > Workspaces**.
These presentation settings do not grant or revoke roles, change balances,
delete records or disable access to Workforce Employee. Hidden sections can be
shown again. Source records and server permissions remain authoritative.

A visibility change preserves an existing edit and explains that its section is
hidden. After saving or cancelling, navigation returns to an available workspace.
Changed configuration sources require review before a draft can be submitted.

## Protected configuration

Active desktop staff read a minimal company and person bound configuration.
Only current Administrators can save it. Revision checks, company locking,
actor and payload bound retry receipts, and immutable events protect updates.
Anonymous callers, ordinary Employees and direct client table writes are denied.

An exact missing-function response from an older backend preserves compatible
default visibility with editing unavailable. Authentication, network, malformed
or wrong-scope responses never silently become defaults. Credentials remain in
memory. See [Account Manager](ACCOUNT-MANAGER.md) for responsibility assignment.
