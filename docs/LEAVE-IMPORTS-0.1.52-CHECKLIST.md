# Desktop0.1.52 — leave request imports

Open **Reports > Leave import** as HR or Administrator.

- Save a CSV/Excel template. Fill in employee/type codes, start/end dates,
  full/am/pm duration, reason and optional private reference.
- Open a file with opposite half-days, several employees or several dates. The
  preview should account for earlier rows' reservations. Duplicate halves,
  overlaps, unknown/archived personnel and insufficient balances block the batch.
- Export row review/errors as CSV or Excel. Source row numbers and literal text
  should remain intact. Existing destination files must be preserved.
- Enter the private import note and preview all rows. Check charged days and
  availability. Opening balances and future calendars/policies must apply.
  Preview must leave no lasting bookings or import history.
- Submit the complete reviewed file. All rows should appear as Pending; normal
  charge dates, approval steps and policy revisions remain visible.
- Open Leave to review or cancel using normal permissions. Reload import history
  to see the current status and approval-step progress. Private references stay
  HR/Admin-only; row reasons remain ordinary leave reasons.
- After an interrupted confirmation, reload history or retry the exact batch.
  Review/cancellation must not create duplicate requests on retry.
- Managers cannot open this import tab. Changing protected access clears drafts
  and private history; unsaved source/submission drafts participate in close checks.
