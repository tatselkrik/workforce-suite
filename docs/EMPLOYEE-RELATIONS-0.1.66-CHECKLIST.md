# Employee relations — HRIS0.1.66 testing checklist

Delivered/installed0.1.66; see the separate delivery evidence.

- Open Employees > Employee relations and Load assigned cases. Administrators have
 company oversight; an HR Generalist sees assigned cases. Unrelated roles have no tab.
- Create a clearly fictional case: choose employee, title, category, priority,
 confidential description and handler. HR Generalists assign a new case to themselves;
 Administrators can choose an active HR/Admin handler. Save case change.
- Open that case, then Add note. The edit form identifies its case and employee.
 Save, refresh and inspect retained history, actor, timestamp and revision.
- Add a dated follow-up. Try resolving while it is pending: completion is required.
 Record completion with a note; verify the original task/due date and completion
 remain. Change status with a reason, resolve, close and test Admin-only reopening.
- Use Assign handler as Administrator. After refreshing, the former HR handler must
 lose its case/details/history and affected open draft. A Manager relationship or
 an employee's own record must not disclose the case. Combined roles preserve scope.
- Open a draft and refresh while another authorized actor saves. Review the current
 version before saving. An uncertain delivery retains Retry same save with fixed
 contents; a confirmed rejection requires explicit review/cancellation.
- Check search/status filters, overdue follow-ups and normal/compact/dark125 layouts.
 Scroll long forms to Save case change/Cancel draft and scroll the full case history.
 Existing unsaved-work guards include case drafts. Closed records stay in history.
- Verify no case contents appear in My payslips, Payroll Desktop, the local portal,
 profile,201files, general reports or notifications. This increment has no case
 attachment/export/delete control and does not automate disciplinary/legal decisions.
